# Nocturne

Неофициальный десктоп-клиент **VK Музыки** для Windows: интерфейс в стиле iOS / Apple Music, «остров» в духе Dynamic Island сверху экрана, глобальные горячие клавиши и анимированные обои (в том числе видео).

> **Nocturne не связан с VK.** Это сторонний клиент, который работает через вашу собственную веб-сессию vk.ru — так же, как браузер. Если VK изменит веб-версию, часть функций может временно перестать работать. Используйте на свой риск.

## Что умеет

- **Для вас** — разделы каталога VK Музыки, «VK Микс» (бесконечный поток), «Собрано алгоритмами», похожие треки; **Обзор** — новинки, чарты, подборки.
- **Моя музыка** — вся медиатека с быстрым поиском по ней; добавление и удаление треков (с отменой).
- **Плейлисты** — создание, переименование, описание, удаление; добавление и удаление треков; альбомы и чужие плейлисты можно добавить к себе.
- **Друзья** — музыка и плейлисты друзей (если они её не скрыли).
- **Поиск** — треки, альбомы и плейлисты; страницы исполнителей.
- **Сейчас играет** — большая обложка, живой размытый фон из обложки, очередь с перетаскиванием и остатком времени, синхронизированный текст песни (если он есть в VK).
- **Остров** — компактная «пилюля» сверху экрана (обложка + эквалайзер в цвете трека). Наводите курсор — раскрывается в плеер: перемотка, громкость, пауза, переключение, «в мои аудио». Клики мимо острова проходят к окнам под ним, в полноэкранных играх и видео он прячется, монитор выбирается в настройках.
- **Горячие клавиши** — глобальные и настраиваемые (по умолчанию `Ctrl+Alt+Space` — пауза, `Ctrl+Alt+→/←` — треки, `Ctrl+Alt+↑/↓` — громкость, `Ctrl+Alt+L` — в мои аудио, `Ctrl+Alt+I` — остров, `Ctrl+Alt+M` — окно). Медиаклавиши и плашка Windows с обложкой работают всегда.
- **Обои** — по обложке текущего трека, встроенные анимированные градиенты или свой файл: MP4, WebM, GIF, JPG, PNG, WebP. Настраиваются размытие и затемнение, акцентный цвет — из обложки или фиксированный.
- Трей, сворачивание в трей, восстановление очереди и позиции после перезапуска, трансляция трека в статус VK (по желанию).

## Приватность и безопасность

- Вход происходит на настоящей странице VK в отдельном окне. **Nocturne не видит и не хранит ваш пароль.**
- Токен веб-сессии живёт только в памяти процесса (Rust) и никогда не попадает в интерфейс, на диск или в логи. Запросы уходят только на `api.vk.ru` и CDN VK.
- Окно входа не имеет доступа к командам приложения. Темп запросов — как у браузера (не больше 3 в секунду), массовых действий приложение не делает.
- Только прослушивание: Nocturne не скачивает и не сохраняет аудио.

## Установка

Скачайте установщик `Nocturne_x.y.z_x64-setup.exe` со страницы релизов и запустите. Нужна Windows 10/11 (WebView2 доставится автоматически, если его нет).

## Сборка из исходников

Нужны Node.js 20+, Rust (stable, MSVC) и Visual Studio Build Tools с компонентом C++.

```bash
npm install
npm run tauri dev      # разработка
npm run tauri build    # установщик в src-tauri/target/release/bundle/nsis
```

`npm run dev` запускает интерфейс в обычном браузере в демо-режиме (выдуманные данные, без VK) — удобно для вёрстки.

Проверки: `npm run typecheck`, `npm test`, `cd src-tauri && cargo test`.

## Как это устроено

- **Tauri 2** (Rust) + **React / TypeScript** в WebView2.
- Rust держит скрытое окно с vk.ru и получает в нём короткоживущий веб-токен (`login.vk.ru/?act=web_token`), затем сам ходит в `api.vk.ru` (v5.289) с лимитом запросов, обновлением токена и повторами.
- Потоки HLS (AES-128) играет `hls.js` через собственный загрузчик, который получает плейлисты, сегменты и ключи через Rust-прокси (только домены CDN VK).
- Остров — отдельное прозрачное окно поверх всех; Rust опрашивает курсор и делает «сквозными» все области вне формы острова.
